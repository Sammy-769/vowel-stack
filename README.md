# Vowel Stack

**Build words. Beat the lava. Save Cubey.**

Vowel Stack is a fast-paced portrait Android word-survival game where
you create words from falling letter blocks while helping Cubey escape
rising lava.

Longer words earn bigger scores, quick word chains build combos, and
every word helps Cubey learn English and unlock new dialogue as he
progresses from **A1 to C2**.

## Features

-   Build words from physics-based falling letter tiles
-   Play through 10 challenging Levels
-   Survive and chase high scores in Endless mode
-   Build combos and use power-ups
-   Complete daily challenges and earn rewards
-   Customize Cubey with colors and outfits
-   Unlock fonts and gameplay backgrounds
-   Climb the online leaderboard
-   Help Cubey learn English from A1 to C2
